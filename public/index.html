01 / WHAT FITS?

A fit is not a forecast.

The comparison below is about algorithm suitability for a CPU/browser experiment. It is not a live-profit ranking. Real returns depend on hardware, power price, network difficulty, pool terms, and market price.

RECOMMENDED FOR STUDYA

Monero XMR

PROOF-OF-WORKRandomX

Monero's official documentation describes RandomX as CPU-optimized and designed to discourage specialized ASIC hardware. A browser can demonstrate hashing, but a browser implementation is not the same as an efficient, pool-connected Monero miner.

CPU learning fitStrong
!

Profitability: unknown here. No live network, exchange, power-price, or pool data is connected, so this site will not estimate real XMR earnings.

Bitcoin BTC

SHA-256 proof-of-work

Poor browser fit

Mining is competitive proof-of-work; a browser CPU is not a practical route against purpose-built hardware. Bitcoin's own explainer describes mining as the competitive process that secures blocks.

Bitcoin.org · How it works ↗
C

Ethereum ETH

Proof-of-stake consensus

Not mineable

Ethereum switched from proof-of-work to proof-of-stake in 2022. ETH is not a coin to mine with this browser—or with a conventional mining rig.

Ethereum.org · Proof of stake ↗
i

How to read this: “Best fit” means closest match to CPU-oriented proof-of-work among these examples. It does not mean highest expected return. Browser throttling, tab suspension, and overhead make browser mining less capable than dedicated software and hardware.

04 / THE FINE PRINT, UP FRONT

Open about the
trade-offs.

01

Device & energy

Browser work uses your processor. Heat, fan noise, battery drain, and electricity use vary by device and workload. The page uses a low default duty-cycle target and pauses when hidden.

02

No real payout estimate

Any real mining return depends on hardware, power price, network difficulty, pool fees, uptime, and asset price. None of those live inputs are connected here; no yield is promised.

03

Privacy & address storage

The optional public address is saved in local browser storage on this device. It is not sent to a server by this prototype. Anyone with access to this browser profile may be able to inspect its local storage.

04

Pool terms & operators

No pool is selected or connected. Real pools can have payout thresholds, fees, and operator risks. Review their terms and verify the destination before any real mining setup.
